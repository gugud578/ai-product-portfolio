范围控制 · SCOPE

主动范围裁剪：这一期只做教师侧最小闭环

建考试 → 收作答 → 批改 → 障碍诊断 → 班级报告。不追求产品四环（OCR 批改 → 障碍诊断 → 自适应练习 → 间隔复习）的全集，本期只交付教师侧前半环，也不做学生端。

3处刻意不做
01建考试→ 02收作答→ 03批改→ 04障碍诊断→ 05班级报告
刻意不做的三件事
裁剪 01
不做试卷 OCR
真卡实测答案落对率 18.8%，未达标即搁置、不合并。 宁可让教师手动录入，也不交付一个会悄悄读错的入口。
裁剪 02
不做学生端
先解决教师最痛的一环：一次考后错因分析 6–10 小时。 学生端与家长端目前仅有 HTML 原型，后端为 0 字节占位，本期不交付。
裁剪 03
不交付未完成页面
未交付的页面不渲染假入口。教师看到的每一个按钮背后都有真实实现， 避免「点了没反应」消耗信任。
